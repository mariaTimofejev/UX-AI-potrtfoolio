# UX-AI-potrtfoolio
UX ja Äriinfotehnoloogia taustaga lõpetaja, kes keskendub kasutajakogemuse ja veebilehtede loogika parandamisele. Kasutan AI-d ja praktilist lähenemist probleemide lahendamiseks ning digilahenduste arendamiseks.

## Minust
- Bakalaureusekraad Äriinfotehnoloogias (TalTech)
- Kasutan AI-d igapäevaselt koodi, õppimise ja probleemide lahendamise jaoks
- Järjepidev enesearendaja (koolitused, iseseisev õppimine, katsetamine)
- Huvi: UX disain, tootearendus ja AI-põhised lahendused

## Millele keskendun

- UX ja kasutusmugavuse parandamine
- Infoarhitektuur ja kasutajavoogude loogika
- Keerukate süsteemide lihtsustamine
- Praktilised AI rakendused tootearenduses
- Õppimine läbi reaalse ehitamise
